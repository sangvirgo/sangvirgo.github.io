🎬 Cinestar — Distributed Cinema Booking
GitHub ↗
Core challenge: Eliminate double-booking under extreme concurrent load without pessimistic locks
  • Atomic concurrency control — single MongoDB atomic update replaces "Read-Check-Write", eliminating race conditions at DB level with no locking overhead
  • ACID multi-document transactions — full payment-to-seat-confirmation flow wrapped in one @Transactional; either both commit or everything rolls back — no ghost bookings
  • 4-node MongoDB Replica Set — 1 Primary + 3 Secondaries with automatic leader election; Primary failure recovered in seconds
  • Read/write separation — ~90% of read traffic routed to Secondary nodes via secondaryPreferred, keeping Primary free for writes
  • Soft-lock expiry sweeper — @Scheduled job releases HOLDING seats not paid within 5 min, maintaining high seat pool turnover
  • 2dsphere geospatial index — efficient "Nearby Cinema" discovery via MongoDB native geo-indexing
